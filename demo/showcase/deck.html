These are speaker notes. Every slide can have them: put the text in an aside element and press N while presenting. The first part of this deck uses only the neutral core; the themes follow at the end, one section each.

A deck is a list of sections

  • Normal HTML and CSS, one section per slide
  • Two files to link, no install
  • Everything else is automatic

Came in with cube-y.

<section data-enter="cube-y">
  <h2>Second slide</h2>
  <p>240 LED</p>
  <img src="photo.png">
  <aside>Notes</aside>
</section>
The source of a deck is just sections. The engine moves them onto a 1920 by 1080 stage, scales it to the screen and adds the animations.

The neutral core's transitions: data-enter="name" on the section; going back plays it in reverse. Themes add more, shown at the end of this deck. Came in with vortex.

Slides without data-enter take the next transition from a cycle. Going back plays the leaving slide's transition in reverse.

Themes add more, and mix

  • The core is neutral, like this part
  • A theme adds transitions, effects, backgrounds
  • Link any number of themes in one deck

Each theme has a section at the end. All themes: themes/README.md. Came in with iris.

<script src="themes/pixelpine/theme.js" defer>
<script src="themes/train/theme.js" defer>
<script src="engine.js" defer>

Every name is unique across the core and all themes, so one deck can use the LED wipes of one theme and the cards of another. Themes are linked before the engine. New themes are welcome as pull requests.

Clickers that send PageUp and PageDown work. The mouse side buttons work whether the driver sends them as buttons, keys or browser history. Came in with cube-y.

Theme: pixelpine

The LED tree

LED-matrix wipes and a twinkling LED background, from the PixelPine Christmas tree talk.

Came in with led-radial, data-ambient="leds" behind it.

The pixelpine theme: four LED wipe transitions and the LED matrix background. Its LEDs glow in data-led-color, here the tree's warm yellow, while the rest of the deck keeps the neutral accent.

led-rain

LEDs light up falling like rain, cover the screen, then switch off.

led-spiral
