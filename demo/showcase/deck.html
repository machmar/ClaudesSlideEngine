These are speaker notes. Every slide can have them: put the text in an aside element and press N while presenting. This deck shows what the engine does; each slide says which transition brought it in.

A deck is a list of sections

  • Normal HTML and CSS, one section per slide
  • Two files to link, no install
  • Everything else is automatic

Came in with led-radial

<section data-enter="cube-y">
  <h2>Second slide</h2>
  <p>240 LED</p>
  <img src="photo.png">
  <aside>Notes</aside>
</section>
The source of a deck is just sections. The engine moves them onto a 1920 by 1080 stage, scales it to the screen and adds the animations.

scroll wheel, Goverview: scroll to pick, → opens, ← returns

Clickers that send PageUp and PageDown work. The mouse side buttons work whether the driver sends them as buttons, keys or browser history. Came in with vortex.

Made for Claude to write

  • You give Claude the material and the talk length
  • Claude writes the slides and notes, following CLAUDE.md
  • build.py packs everything into one HTML file
