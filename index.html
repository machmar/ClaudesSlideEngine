Claude's Slide Engine

Animated slides from plain HTML

3D cube turns, an iris, blinds, a vortex; headings that build letter by letter, numbers that count up, clips that switch on, a slide overview on the mouse wheel, speaker notes and a talk timer. Themes add a look on top (LED wipes, …) and mix freely: see the catalogue.

Showcase →Every effect and every control, in 12 slides. PixelPine →A real 11-slide talk about a PCB Christmas tree (in Czech).

Works in Firefox, Chrome and Edge on a computer. → next, ← back, scroll for the overview, F full screen, H all controls.

Made for Claude to build presentations with, not really for people to use directly. See the repository.
